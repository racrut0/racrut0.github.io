Задача
Дать заказчику возможность быстро понять, с какими задачами ко мне можно обратиться, и посмотреть конкретный результат.
Моя роль

HTML, CSS и JavaScript. Статический сайт опубликован на GitHub Pages.
01 / Структура

Путь от задачи к работе

Первый экран

Краткое предложение и три примера: Telegram-бот, бумажные каталоги и сайт.

Проекты с деталями

Для каждой работы — задача, моя роль, результат и ссылка на материалы или демонстрацию.

Готовые файлы

Облегчённые каталоги, исходные PDF, презентация и примеры оформления доступны без входа.

Понятное начало работы

Подсказки под разные задачи помогают собрать материалы до первого сообщения.

02 / Адаптация

Удобно с телефона

Крупный текст и простая навигация

На узком экране блоки складываются в одну колонку. Ссылки и кнопки остаются заметными, изображения можно открыть крупнее.

Без лишней загрузки

Изображения ниже первого экрана загружаются по мере просмотра. Видео запускается только по нажатию, а полные каталоги вынесены в отдельные ссылки.

Управление с клавиатуры

У вкладок есть переключение стрелками, у галереи — закрытие по Escape и возврат фокуса к кнопке.

Результат

Публичный сайт
с живыми примерами.

Его можно отправить заказчику одной ссылкой. Внутри доступны кейсы, файлы и демонстрация интерфейса.
