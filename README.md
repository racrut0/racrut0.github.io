# Портфолио Андрея Исупова

Публичный сайт: https://racrut0.github.io/

Статический сайт для GitHub Pages. Главная страница — `index.html`, демонстрация календаря — `advent/`, каталоги и исходные PDF — `catalogs/`.

Для публикации GitHub Pages использует ветку `main` и корневую папку `/`. Сборка и сервер приложению не нужны. После изменения файлов и отправки в `main` сайт обновляется автоматически.

В портфолио представлены учебные и личные проекты, созданные с использованием ИИ-инструментов. IIDOUBLE находится в разработке. Скриншоты содержат искусственные тестовые данные. Каталоги опубликованы как примеры оформления; цены относятся к дате сборки файлов. PDF сохранены без изменений.
