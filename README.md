# Портфолио Андрея Исупова

Публичный сайт: https://racrut0.github.io/

Сайты, Telegram-боты и каталоги продукции. В портфолио — личный проект IIDOUBLE, готовые каталоги GRASS, DETAIL и Shine Systems, а также демонстрационный адвент-календарь.

Статический сайт для GitHub Pages. Главная страница — `index.html`, календарь — `advent/`, каталоги и оригинальные PDF — `catalogs/`. Публикация из ветки `main`, корневая папка `/`. После отправки изменений сайт обновляется автоматически.

IIDOUBLE находится в развитии. Скриншоты содержат тестовые данные. PDF-каталоги сохранены без изменений, цены относятся к дате сборки файлов.
