# Портфолио Андрея Исупова

Публичный сайт: https://racrut0.github.io/

Сайты, Telegram-боты, бумажные каталоги и дизайн материалов.

На главной — четыре проекта с фильтром по направлению, краткое описание услуг и контакт. Подробности, галереи и файлы вынесены в проекты.

- `projects/iidouble/` — собственный продукт в разработке, сценарии и демонстрация.
- `projects/portfolio/` — структура, визуальная концепция и адаптация сайта.
- `catalogs/` — пять бумажных каталогов. Оригиналы и облегчённые PDF.
- `design/` — карточки товара, меню и презентация.
- `iidouble-demo/` — отдельная демонстрация с подготовленными ответами, без серверной части.

Меню и карточки товара подписаны как концепты. Характеристики товара и цены меню условные.

Сайт работает без сборки и внешних библиотек. Публикация на GitHub Pages из ветки `main`, корневая папка `/`.
