# Портфолио Андрея Исупова

Публичный сайт: https://racrut0.github.io/

Создание и доработка сайтов, Telegram-боты, оформление бумажных каталогов, презентаций, меню и карточек товаров.

В портфолио: IIDOUBLE с отдельным кейсом и интерактивной демонстрацией, кейс сайта-портфолио, пять готовых бумажных каталогов и примеры оформления.

Главная — `index.html`, кейсы — `projects/`, каталоги — `catalogs/`, примеры дизайна и файлы — `design/`, демонстрация интерфейса — `iidouble-demo/`.

IIDOUBLE находится в развитии. Публичная демонстрация использует подготовленные ответы, работает без серверной части и сбрасывает изменения после обновления страницы. Меню и карточки товара подписаны как демонстрационные концепты.

Оригиналы каталогов сохранены без изменений. Для просмотра доступны отдельные облегчённые копии. Цены в каталогах относятся к дате сборки файлов.

Статический сайт опубликован через GitHub Pages из ветки `main`, корневая папка `/`.
